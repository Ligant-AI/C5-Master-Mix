# Master Mix

Master Mix (C5), a Ligant Bench Tool. Plain ES modules, no framework, built with Vite. Runs entirely in the browser.

```
npm install
npm run dev            # http://localhost:5175/
npm test               # node --test
npm run test:headless  # Playwright smoke check against the dev server
```
